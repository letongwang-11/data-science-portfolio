## Project Showcase
### 1. Student Academic Performance Analysis
- **Research question**: Which factors most strongly predict secondary school students' final grades, and can a simple model identify at-risk students early?
- **Key finding**: Study time and past failures are the strongest predictors; a logistic regression model achieves ~75% accuracy in flagging at-risk students.
